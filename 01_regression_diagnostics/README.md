# Regression Diagnostics and Loss Functions

Demonstrates linear regression on the diabetes dataset. The script calculates **MSE**, **RMSE**, and **MAPE**, then produces diagnostic plots for key linear-regression assumptions: linearity, residual normality, homoscedasticity, and independent errors.

It also uses validation curves to illustrate the **bias-variance trade-off**: overly simple models underfit; overly flexible models can overfit.

Run: `python 01_regression_diagnostics/run_regression.py`
